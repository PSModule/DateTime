# DateTime

DateTime is intended to be a PowerShell module for working with DateTime objects.

## Status

This repository is currently a placeholder. The module source still contains scaffold code, so there are no supported commands or usage examples to document yet. Any files under `examples/` are scaffold placeholders and are not supported.
